# Project Notes and Assumptions

- Project limited to 4 hour time limit as specified in the brief.
- Fonts are slightly wrong. Did not have access to proper font (FatFrank) files so used a close match.
- Some animation was doing using vanilla css, could have used a library like Framer Motion, but due to time limit I chose not to.
- Assumed what the mobile menu would look like, designs for this were not specified so used a judgement. Would clarify this in a real world scenario.
- Added in some hover effects on the buttons and links. They weren't specified but felt it added to the design.

# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/)

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).
